## Reporting a Vulnerability

We take the security of this project seriously.

If you believe you have found a security vulnerability in this project, please report it privately. **Do not create a public issue.**

To report a vulnerability, please reach out to the repository owners directly, or submit a private vulnerability report via GitHub if enabled for this repository.

Please provide as much information as possible:
* A description of the vulnerability and its impact
* Steps to reproduce the issue
* Potential fixes or workarounds, if you know of any

We will review the issue, and provide an initial response within 3 business days. If the vulnerability is confirmed, we will work on a fix and release it as quickly as possible.
